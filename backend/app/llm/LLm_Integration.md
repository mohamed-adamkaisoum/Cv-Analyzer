1. Installation de Ollama
Dkhel hna : https://ollama.ai
Clique sur "Download"
Sélectionne "Windows"
Télécharge l'installer
2. Une fois on finit l'installation on s'assure que ollama est installé avec la cmd: 
ollama --version

3. Ensuite on telecharge le model mistral avec la cmd : 
ollama pull mistral 
4. on lance ollama :
ollama serve

*Et c'est bon*
